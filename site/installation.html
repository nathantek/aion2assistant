Installation

Cinq étapes, environ cinq minutes. Windows 64 bits requis.

Télécharger

Windows 64 bits · gratuit · GPL-3.0

Code signing policy

  1. Installer Npcap

    Aion2Assistant a besoin de Npcap pour lire le trafic réseau du jeu. Télécharge-le depuis npcap.com et lance l'installateur.

    Important : ne coche pas l'option « Restrict Npcap driver's access to Administrators only ». Laisse-la décochée, sinon l'app ne pourra pas capturer sans droits administrateur.

  2. Décompresser l'archive

    Télécharge le zip Aion2Assistant-<version>-win-x64.zip avec le bouton ci-dessus, puis décompresse-le dans un dossier de ton choix.

  3. Lancer l'application

    Double-clique sur Aion2Assistant.exe. Au premier lancement, le contrat de licence (CLUF) s'affiche : lis-le et accepte pour continuer.

    Comme cette bêta n'est pas signée, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis sur « Exécuter quand même ». Voir aussi la FAQ.

  4. Jouer en fenêtré sans bordure

    Dans les options graphiques d'AION 2, choisis le mode fenêtré sans bordure. En plein écran exclusif, le jeu masque les overlays et l'application ne sera pas visible.

  5. Vérifier le fichier optionnel

    Chaque version publie l'empreinte SHA-256 du zip dans ses notes (page Versions). Ouvre PowerShell dans le dossier du zip et lance Get-FileHash .\Aion2Assistant-*.zip : la valeur affichée doit être identique. Si elle diffère, ne lance pas l'app.

Désinstaller

Aion2Assistant n'installe rien en dehors du dossier que tu as décompressé : pas de service, pas de clé de registre, pas de raccourci ni de démarrage automatique. Toutes ses données sont dans %AppData%\Aion2Assistant.

  1. Fermer l'application

    Fais un clic droit sur l'icône d'Aion2Assistant dans la zone de notification (à côté de l'horloge), puis choisis Quitter.

  2. Supprimer le dossier de l'application

    Supprime le dossier dans lequel tu as décompressé le zip.

  3. Supprimer tes données

    Appuie sur Win + R, tape %AppData% puis valide avec Entrée. Dans le dossier qui s'ouvre, supprime le dossier Aion2Assistant : réglages, historique, records, sons, captures et journaux.

  4. Désinstaller Npcap optionnel

    Si aucun autre programme ne l'utilise (Wireshark par exemple), désinstalle Npcap depuis Paramètres › Applications › Applications installées.
