Installation

Quatre étapes, environ cinq minutes. Windows 64 bits requis.

Télécharger

Windows 64 bits · gratuit · GPL-3.0

Code signing policy

  1. Installer Npcap

    Aion2Assistant a besoin de Npcap pour lire le trafic réseau du jeu. Télécharge-le depuis npcap.com et lance l'installateur.

    Important : ne coche pas l'option « Restrict Npcap driver's access to Administrators only ». Laisse-la décochée, sinon l'app ne pourra pas capturer sans droits administrateur.

  2. Lancer l'installateur

    Télécharge Aion2Assistant-win-Setup.exe avec le bouton ci-dessus et lance-le. Il installe l'app pour ton compte Windows, sans droits administrateur, dans %LocalAppData%\Aion2Assistant, et crée un raccourci sur le Bureau et dans le menu Démarrer. Au premier lancement, le contrat de licence (CLUF) s'affiche : lis-le et accepte pour continuer.

    Comme cette bêta n'est pas signée, Windows SmartScreen affiche une fois « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis sur « Exécuter quand même ». Voir aussi la FAQ.

  3. Jouer en fenêtré sans bordure

    Dans les options graphiques d'AION 2, choisis le mode fenêtré sans bordure. En plein écran exclusif, le jeu masque les overlays et l'application ne sera pas visible.

  4. Vérifier le fichier optionnel

    Chaque fichier d'une version est accompagné de son empreinte SHA-256 (fichier .sha256 sur la page de la version). Ouvre PowerShell dans le dossier du fichier téléchargé et lance Get-FileHash .\Aion2Assistant-win-Setup.exe : la valeur affichée doit être identique. Si elle diffère, ne lance pas le fichier.

    Tu peux aussi vérifier d'où vient le fichier : depuis la 0.3.6, chaque fichier publié a une attestation de build qui prouve qu'il a été construit par GitHub Actions à partir du dépôt public. Avec GitHub CLI, lance gh attestation verify Aion2Assistant-win-Setup.exe --repo nathantek/aion2assistant : la vérification doit réussir.

Version portable

Tu préfères ne rien installer ? Sur la page de la version, télécharge Aion2Assistant-win-Portable.zip, décompresse-le dans le dossier de ton choix et lance Aion2Assistant.exe. La version portable se met aussi à jour toute seule.

Mises à jour

Une fois installée, l'app se met à jour toute seule. Elle vérifie GitHub au démarrage puis toutes les 6 heures, télécharge la nouvelle version en arrière-plan et affiche un bandeau « Version X prête ». La mise à jour s'installe quand tu cliques sur Redémarrer, ou à la fermeture de l'app si tu choisis Plus tard. Tu peux tout désactiver dans Réglages › À propos.

Passer de l'ancien zip à l'installateur

Si tu utilisais une version téléchargée en zip (0.3.3 ou avant) :

  1. Fermer l'ancienne version

    Clic droit sur son icône dans la zone de notification, puis Quitter. Sinon, la nouvelle version ne pourra pas démarrer : une seule instance de l'app peut tourner à la fois.

  2. Installer avec Setup.exe

    Suis l'étape Lancer l'installateur ci-dessus.

  3. Supprimer l'ancien dossier

    Supprime le dossier où tu avais décompressé l'ancien zip. Tes réglages, ton historique, tes records et tes sons sont conservés : ils sont dans %AppData%\Aion2Assistant, que la nouvelle version réutilise.

Désinstaller

L'installateur ne crée ni service ni démarrage automatique. Il ajoute l'app à la liste des applications installées de Windows et crée deux raccourcis, retirés à la désinstallation. Toutes tes données sont dans %AppData%\Aion2Assistant.

  1. Fermer l'application

    Fais un clic droit sur l'icône d'Aion2Assistant dans la zone de notification (à côté de l'horloge), puis choisis Quitter.

  2. Désinstaller l'application

    Ouvre Paramètres › Applications › Applications installées, cherche Aion2Assistant, puis choisis Désinstaller. Pour la version portable, supprime simplement son dossier.

  3. Supprimer tes données

    Appuie sur Win + R, tape %AppData% puis valide avec Entrée. Dans le dossier qui s'ouvre, supprime le dossier Aion2Assistant : réglages, historique, records, sons, captures et journaux.

  4. Désinstaller Npcap optionnel

    Si aucun autre programme ne l'utilise (Wireshark par exemple), désinstalle Npcap depuis Paramètres › Applications › Applications installées.
