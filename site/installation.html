Installation

Quatre étapes, environ cinq minutes. Windows 64 bits requis.

Télécharger

  1. Installer Npcap

    Aion2Assistant a besoin de Npcap pour lire le trafic réseau du jeu. Télécharge-le depuis npcap.com et lance l'installateur.

    Important : ne coche pas l'option « Restrict Npcap driver's access to Administrators only ». Laisse-la décochée, sinon l'app ne pourra pas capturer sans droits administrateur.

  2. Décompresser l'archive

    Télécharge le zip Aion2Assistant-<version>-win-x64.zip avec le bouton ci-dessus, puis décompresse-le dans un dossier de ton choix.

  3. Lancer l'application

    Double-clique sur Aion2Assistant.exe. Au premier lancement, le contrat de licence (CLUF) s'affiche : lis-le et accepte pour continuer.

    Comme cette bêta n'est pas signée, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis sur « Exécuter quand même ». Voir aussi la FAQ.

  4. Jouer en fenêtré sans bordure

    Dans les options graphiques d'AION 2, choisis le mode fenêtré sans bordure. En plein écran exclusif, le jeu masque les overlays et l'application ne sera pas visible.
