# Contribuer

Merci de ton intérêt pour Aion2Assistant.

- **Issues** : signale un bug ou propose une idée via les issues du dépôt. Indique la version (Options › À propos) et les étapes pour reproduire.
- **Pull requests** : les PR sont acceptées. Garde-les petites et ciblées, une idée par PR.
- **Style du code** : suis les conventions existantes (C# / .NET 8, nullable activé). Le projet doit compiler sans erreur avec `dotnet build Aion2Assistant.sln -c Release`.
- **Pas de données de capture** : n'ajoute jamais de fichiers `.pcap`, `.pcapng`, `.db` ou `.log`, ni de captures réseau, dans une issue ou une PR.
- **Licence** : en contribuant, tu acceptes que ton code soit publié sous GPL-3.0.
